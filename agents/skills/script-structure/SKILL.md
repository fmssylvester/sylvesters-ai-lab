# Script Structure Skill

## Workflow

1. **Hook (0-30s)**: Deliver direct value promise within 5 seconds. Show proof of concept.
2. **Avatar Pattern Interrupts**: Insert talking head beats every 60-90 seconds at major concept shifts.
3. **Tutorial Core**: Deliver technical steps cleanly with paired visual intent annotations.
4. **Outro**: Execute channel-specific CTA bridging directly to the template.
