Do I need technical skills to set these up?
Basic familiarity with n8n helps, but the setup guide walks you through every step. Import, add your API key, activate. About 5 minutes. The Pro tier includes step-by-step installation help.
What do I need to run the CS Agent?
An n8n instance (free self-hosted or cloud at app.n8n.cloud) and an OpenAI API key. Total cost per conversation is ~$0.002 with GPT-4o-mini.
What do I need to run the SMS Bot?
n8n (any version), an OpenAI API key, and a Twilio account with an SMS-capable phone number.
Can I customize the responses?
Yes. Both templates have editable system prompts. Change the brand voice, add product knowledge, or connect custom tools.
What do I need to run Patient Records Lookup?
An n8n instance (free self-hosted or cloud) and a Google Sheets document with patient data. That's it. No OpenAI key required — data is looked up directly from your sheet.
Can patients access their own records?
The dashboard gives secure access to staff only. Patients interact through the channels you set up — you control who can search and what they see.
What do I need to run the AI Agent?
An n8n instance (free self-hosted or cloud) and an OpenAI API key. The Calculator and Wikipedia tools work without any extra keys. Total cost per query is ~$0.001 with GPT-4o-mini.
Can I add more tools to the AI Agent?
Yes. The workflow is designed to be extensible. Add any n8n-supported tool node (SerpAPI for web search, vector store for knowledge base, etc.) and connect it to the AI Agent's ai_tool input. The agent automatically discovers new tools.
Does the AI Agent remember previous conversations?
Yes. It has a 20-message window buffer memory. Pass a sessionId in your request to continue previous conversations. Without it, each request starts fresh.
What about Nigerian payment?
Gumroad accepts Nigerian debit cards (Verve, Mastercard). The price is in USD but your bank converts at the current rate (~₦1,370/USD). $29 ≈ ₦40,000.
