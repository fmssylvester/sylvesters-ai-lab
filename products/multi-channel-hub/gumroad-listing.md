## Product Title
Multi-Channel Communication Hub — n8n Workflow Template

## Description
Unify your customer communications across WhatsApp, Telegram, and SMS in one powerful n8n workflow. The Multi-Channel Hub automatically detects which channel a message arrives on, generates an AI response optimized for that channel, and sends the reply back — all in one seamless workflow.

**Perfect for:**
- Service businesses managing multiple messaging channels
- E-commerce stores with WhatsApp + Telegram support
- Agencies building omnichannel solutions for clients
- Any business wanting a single inbox for all channels

**What's included:**
- Ready-to-import n8n workflow JSON
- AI-powered response generation (GPT-4o-mini)
- Channel-aware replies (WhatsApp professional / Telegram casual / SMS short)
- WhatsApp Business API integration
- Telegram bot integration
- Twilio SMS integration
- Detailed setup guide

**Features:**
- Single webhook endpoint for all channels
- AI detects intent and responds appropriately per channel
- Easy to add more channels (extend the router)
- Works with any frontend or phone system
- Channel-optimized response formatting

**Pricing:**
- **Essentials ($97):** Single use license + setup guide
- **Professional ($197):** Commercial license + priority support + customization
- **Enterprise ($397):** White-label rights + installation + custom channel development

**Requirements:**
- n8n instance (free self-hosted or cloud)
- OpenAI API key
- At least one channel: WhatsApp Business API, Telegram Bot Token, or Twilio account
