# Service Tiers — Automation + Website Bundle

## Tier 1: Workflow Only (₦150k / $99)
- Ready-to-import n8n workflow JSON
- Google Sheets template
- Telegram/SMS/webhook trigger
- Setup guide PDF

## Tier 2: Workflow + Professional Website (₦500k / $349)
Everything in Tier 1, plus:
- Custom professional website (responsive, mobile-first)
- Patient search dashboard
- Login system (simple password or PIN)
- Hosted on Cloudflare (free hosting, zero monthly cost)
- Custom domain setup (theirname.com)
- 1 month support

## Tier 3: Full Clinic System (₦1.2M / $799)
Everything in Tier 2, plus:
- Patient check-in via QR code (patient scans → fills form → reception gets alert)
- Appointment booking widget on website
- Automated SMS reminders to patients
- Doctor's voice search (dictate patient name → records pop up)
- Multi-staff accounts
- 3 months support + training

## Why Tier 2 is the Sweet Spot

| | Tier 1 | Tier 2 | Tier 3 |
|---|---|---|---|
| Price | ₦150k | ₦500k | ₦1.2M |
| Time to deliver | 1 day | 3 days | 2 weeks |
| Perceived value | "Just a file" | "My own system" | "Full solution" |
| Client likely to say yes | Maybe | Yes | Needs trust |

**Pitch strategy:** Lead with Tier 2. If they hesitate, drop to Tier 1. If they're excited, upsell to Tier 3.

## Delivery Process

### Day 1 — Discovery Call (30 min)
- Understand their workflow
- What data they track
- What they want automated

### Day 2-3 — Build
- Set up Google Sheets with their sample data
- Build n8n workflow
- Create website (if Tier 2+)
- Test end-to-end

### Day 4 — Demo & Deploy
- Show them live
- Train staff (20 min)
- Go live

## The Two-Sentence Pitch

> "I build custom automation systems for businesses. I set up a professional website for your practice, and behind the scenes, everything runs automatically — patient lookups, appointment reminders, missed call texts. You look professional online, and your staff saves 15+ hours a week."
