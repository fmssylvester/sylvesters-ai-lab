## Product Title
Patient Records Lookup — n8n Workflow Template

## Description
Give your clinic instant patient record access from any phone. Type a patient name or ID and get a complete medical summary in seconds — allergies, medications, blood type, conditions, and visit history.

Works via Telegram, WhatsApp, SMS, or web dashboard. No expensive EHR system needed. No monthly fees.

**Perfect for:**
- Solo doctors and small clinics (Nigeria, Kenya, India — where EHR adoption is low)
- Dental practices
- Physiotherapy clinics
- Small hospitals with paper-based records
- Pharmacies needing quick patient history lookup

**What's included:**
- Ready-to-import n8n workflow JSON
- Google Sheets template (CSV) for patient data
- Professional patient dashboard HTML (login + search UI)
- Setup guide with step-by-step instructions

**Features:**
- Search by patient name or ID
- Returns: allergies, medications, blood type, conditions, visit history
- Works with Google Sheets (free tier) or Airtable
- Webhook trigger for easy frontend integration
- n8n Data Table integration
- Multi-device: Telegram, WhatsApp, SMS, or Web Dashboard

**How it works:**
1. Import the JSON into your n8n instance
2. Connect your Google Sheets with patient data
3. Expose the webhook — done
4. Doctors text a name → get instant records

**Pricing:**
- **Basic ($49):** Workflow template + Google Sheets template + dashboard
- **Pro ($69):** Template + priority support + WhatsApp integration help
- **Agency ($149):** Commercial license + white-label rights + installation

**Requirements:**
- n8n instance (free self-hosted or n8n.cloud)
- Google Sheets (free tier is sufficient)
