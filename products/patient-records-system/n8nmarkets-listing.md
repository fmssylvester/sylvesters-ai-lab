## Title
Patient Records Lookup System — n8n Workflow Template

## Category
Healthcare / Data Retrieval

## Description
Instantly look up patient records from any device — phone, web, or messaging app. This n8n workflow connects to your Google Sheets or database and returns patient summaries via SMS or API response.

### Features
- Look up patients by name, phone, or ID
- AI-powered response generation (OpenAI)
- Twilio SMS integration for phone-based lookup
- Google Sheets as the data source (easily swap for any DB)
- Works with any frontend via webhook
- Full patient dashboard included (Pulse website)

### Use Cases
- Medical offices checking patient records on the go
- Dental clinics confirming appointment details
- Pharmacies looking up prescription info
- Telehealth services verifying patient identity

### How It Works
1. Patient or staff sends a query (name/ID/phone)
2. Workflow searches the patient database
3. AI generates a concise medical summary
4. Response sent via SMS or API

### What's Included
- `workflow-patient-lookup.json` — n8n workflow
- `google-sheet-template.csv` — sample patient data
- `website/index.html` — Pulse patient dashboard (standalone UI)
- `SETUP.md` — complete setup guide
