Do I need technical skills to set these up?
Basic familiarity with n8n helps, but the setup guide walks you through every step. Import, add your API key, activate. About 5 minutes. The Pro tier includes step-by-step installation help.
What do I need to run the CS Agent?
An n8n instance (free self-hosted or cloud at app.n8n.cloud) and an OpenAI API key. Total cost per conversation is ~$0.002 with GPT-4o-mini.
What do I need to run the SMS Bot?
n8n (any version), an OpenAI API key, and a Twilio account with an SMS-capable phone number.
Can I customize the responses?
Yes. Both templates have editable system prompts. Change the brand voice, add product knowledge, or connect custom tools.
