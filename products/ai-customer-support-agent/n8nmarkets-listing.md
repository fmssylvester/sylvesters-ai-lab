AI Customer Support Agent — n8n Workflow Template

## Description
Deploy a professional AI customer support agent in your n8n instance in under 5 minutes. This ready-to-import workflow handles customer inquiries with contextual AI, conversation memory, and escalation detection.

### Features
- Conversational AI agent with professional support prompt
- 10-message window buffer memory (remembers context across replies)
- Webhook endpoint for any frontend integration
- Automatic escalation detection for complex issues
- Customizable brand voice and system prompt

### Use Cases
- SaaS customer support (tier-1 triage)
- E-commerce order inquiries
- Service business appointment questions
- Internal IT help desk automation

### How It Works
1. Import the JSON into n8n
2. Connect your OpenAI API key
3. Activate the workflow
4. Send POST requests to the webhook URL
