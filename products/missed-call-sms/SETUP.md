# Missed Call SMS Text-Back — Setup Guide

## What It Does
When a customer calls and misses you, this workflow automatically sends a friendly SMS reply — generated by AI — within seconds. Perfect for dentists, doctors, auto shops, salons, and any appointment-based business.

## Requirements
- n8n instance (cloud or self-hosted)
- OpenAI API key
- Twilio account (for sending SMS)

## Setup

### 1. Import the Workflow
1. Open your n8n dashboard → **Workflows** → **Import from File**
2. Select `template.json`

### 2. Configure OpenAI
1. Click **OpenAI Chat Model** node → **Create New** credential
2. Enter your OpenAI API key → **Save**

### 3. Configure Twilio
1. Click **Send SMS via Twilio** node
2. Under **Credential**, create Twilio credentials with:
   - Account SID
   - Auth Token
3. Set **From Number** to your Twilio phone number

### 4. Activate
1. **Save** → toggle **Active** on
2. Your webhook URL: `https://your-n8n.com/webhook/missed-call`

### 5. Connect Your Phone System
Forward missed calls to this webhook URL via Twilio Studio, Twilio Functions, or any telephony provider that supports webhooks.

## Customization
Edit the **SMS Generator Agent** node → **System Message** to change tone, add business-specific info, or adjust the SMS length.
