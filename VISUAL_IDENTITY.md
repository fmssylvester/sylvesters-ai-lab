# Visual Identity Guidelines

## The Problem
Every scene uses the same formula: dark background + radial gradient + bold sans-serif + bottom label. This is generic. We need a signature.

## Our Visual Identity

### Color Palette
**Primary:** Deep Navy (#0A1628) → not pure black
**Accent:** Electric Cyan (#00D9FF) — used sparingly, never as fill
**Warm:** Amber Gold (#E7B84D) — for emphasis and accent lines
**Text:** Pure White (#FFFFFF) with 20% reduced opacity for secondary text
**Danger/energy:** Coral (#FF6B6B) — only for kinetic/energetic scenes

**Rule:** Every scene must use at least 2 of these colors. The background is NEVER pure black — always has a color temperature (cool navy or warm charcoal).

### Background Treatments
**Signature patterns** (pick one per scene, never stack all):
1. **Gradient Mesh** — overlapping radial gradients at different positions, creating organic color pools
2. **Grid Overlay** — thin (0.5-1px) grid lines at 5-10% opacity, creating structure
3. **Noise Texture** — subtle film grain (2-4% opacity) over solid color
4. **Geometric Shapes** — large (300-600px) translucent shapes (circles, rectangles) with blur
5. **Horizontal Bars** — 3-5 stacked translucent bars with slight color gradient

**Rule:** Background must complement the text, never compete. Background elements at max 8% opacity.

### Typography Rules
**Hero text:** 80-140px, font-weight 900, letter-spacing -2 to -4
**Secondary text:** 24-36px, font-weight 500-600, letter-spacing 4-8px uppercase
**Labels:** 14-18px, font-weight 700, letter-spacing 6-10px uppercase

**Rule:** Text must be readable on a 5-inch phone screen at arm's length. When in doubt, go bigger.

### Composition Principles
1. **One focal point** — the hero text is ALWAYS the largest element
2. **Breathing room** — minimum 60px padding from any edge
3. **Depth layers** — foreground (text), midground (accent elements), background (gradient/texture)
4. **Color temperature** — each scene has a dominant temperature (cool OR warm, not both equally)

### What Makes Us Distinctive
1. **Depth through blur** — background elements always have blur, text is always sharp
2. **Intentional motion** — every animation serves the message, never decorative
3. **Typography as hero** — text IS the motion graphics, not a label on top of it
4. **Color restraint** — max 3 colors per scene, used with purpose
5. **Physical feel** — spring physics, anticipation, follow-through (never linear)

### Anti-Patterns (Never Do These)
- Pure black (#000000) backgrounds
- More than 3 colors in one scene
- Text smaller than 60px for hero text
- Radial gradient as the only background element
- Bottom label as the only secondary element
- Linear/ease-in animations (always use spring or ease-out)
- Text that appears all at once (always staggered reveal)
