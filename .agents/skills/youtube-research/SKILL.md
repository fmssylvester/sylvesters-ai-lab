# YouTube Research Skill

## Workflow

1. Execute `python3 pipeline/tavily_research.py` for target topic market coverage.
2. Execute `python3 pipeline/trend_research.py` to identify high-volume search queries and angles.
3. Execute `python3 pipeline/topic_research.py` to map technical subtopics.
4. Output structured insights: Top Hooks, Key Pain Points, and Recommended Angles.
